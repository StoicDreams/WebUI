## Install Tools

<webui-page-segment>

webui

```pwsh
cargo install --path webui --features all
```

webuisave

```pwsh
cargo install --path webuisave
```

webapp_post_build

```pwsh
cargo install --path webapp_post_build
```

saveweb

```pwsh
cargo install --path saveweb
```

</webui-page-segment>

# Website

<webui-page-segment>

The Web UI website is in the WebUIWeb repo, in the Websites folder. Run, test, and publish it from there.

Try local changes to `webui` in a website by running it from that website's `webapp` folder, after installing it above

```pwsh
webui
```

</webui-page-segment>

## Install Tools

<webui-page-segment>

webui

```pwsh
cargo install --path webui --features all
```

webuisave

```pwsh
cargo install --path webuisave
```

webapp_post_build

```pwsh
cargo install --path webapp_post_build
```

saveweb

```pwsh
cargo install --path saveweb
```

</webui-page-segment>

# Website

<webui-page-segment>

Run Local

```pwsh
./PowerShell/RunLocal.ps1
```

Run `trunk serve --open` from your UI project root (e.g. `webapp`) to run your site locally.

```pwsh
Set-Location webapp
trunk serve --open
```
